Lowkey custom emoji assets (128×128 animated GIF).

Style: transparent neon-pulse icons with a subtle breathing glow. The original PNGs remain as source/fallback artwork.

Installed or refreshed into a guild via owner command:
  /emoji-setup

Keys:
  success, error, warning, info, unlock, link,
  health, degraded, down, disabled, gear, chart

The setup command replaces the previous static Lowkey emojis when possible. Unicode fallbacks are used automatically when a custom emoji is missing.
Guild emoji slots: free servers have 50 — this set uses 12.
